## Fastest deployment route

### GitHub

1. Create a GitHub account.
2. Create a repository called `digups-website`.
3. Upload the four website files.
4. Commit the files.

### Render

1. Sign in to Render.
2. Select **New +** → **Static Site**.
3. Connect the GitHub repository.
4. Leave the build command blank.
5. Set publish directory to `.`
6. Deploy.

Render will give you a temporary URL that can be used immediately while the domain is being connected.

## Connect Namecheap domain

1. In Render, open **Settings** → **Custom Domains**.
2. Add your domain and the `www` version.
3. Copy the DNS records Render provides.
4. In Namecheap, open **Domain List** → **Manage** → **Advanced DNS**.
5. Replace parking records with the Render records.
6. Verify the domain in Render.
